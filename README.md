# 🦆 Dale: The School-Safe Desktop Pet

A lightweight, interactive desktop pet built to run directly in the browser. Since many school and work environments restrict "Developer Mode" or browser extensions, **Kaczuha** lives on a web page so you can have a coding companion anywhere.

## ✨ Features
- **Context-Aware Animations:** Swaps between an animated GIF (`kaczuha1.gif`) when resting and a static PNG (`kaczuha 2 1.png`) when moving.
- **Interactive AI:** Kaczuha decides when to wander around the screen or take a nap.
- **Click-to-Move:** You can direct the duck to a specific spot by clicking anywhere on the screen.
- **Responsive Design:** Works on any screen size or browser.

## 🛠️ How I Built It
- **HTML5 & CSS3:** For the "stage" and the pet's positioning.
- **JavaScript (Vanilla):** Used `requestAnimationFrame` for smooth movement logic and `setInterval` for the duck's decision-making "brain."
- **GitHub Pages:** To bypass browser restrictions and host a live version of the tool.

## 📂 Project Structure
- `index.html`: The core logic and structure.
- `kaczuha1.gif`: Idle animation state.
- `kaczuha 2 1.png`: Movement state image.
